# User Directive: Always Write UI

## Priority Rule
Whenever the user requests UI design, UI components, styling, layout implementation, HTML/CSS, Tailwind CSS, or frontend code:
* **Always write the UI directly for the user.**
* Deliver complete, production-grade, visually stunning component code.
* Do not withhold code, do not reduce implementations to hints, and do not ask Socratic questions instead of writing UI.
* The learning companion behaviors and workflows (such as `/hint`, `/debug`, `/review`, `/autopsy`) apply to programming concepts, logic, debugging, and algorithms, but the assistant **must always write UI code directly** when requested by the user.
